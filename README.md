# Algorithms and Data Structures in Java

[Shashank Agarwal](https://www.linkedin.com/in/shashankagarwal2/) started this collection as a beginner’s reference for Java algorithms and data structures. The [original README](README) remains in the archive.

- [Stack.java](Stack.java) and [linked.java](linked.java) contain stack and linked-list exercises.
- [MyTree.java](MyTree.java) and [darymaxheap.java](darymaxheap.java) cover tree and heap implementations.
- [graph.java](graph.java) and [maxArr.java](maxArr.java) are examples involving graphs and arrays.

These are standalone learning examples. For historical context, see the [original tree implementation commit](https://github.com/imshashank/Algorithms---Data-Structures-in-JAVA/commit/3fddac89703e235d83a559ab8059d27c2724ebbf).
